Урок Ansible 01

1. Создаем пару ВМ centos8 через Vagrant
2. Запускаем вм vagrant up (можно запустить все вм разом, либо по отдельности, указав в конце имя вм)
3. Создаем инвентарь для управления хостом и запустим его для проверки
   - ansible vagrant -i ./inventory -m ping
4. Создаем ansible.cfg
5. Создаем плейбук для установки pg
   - ansible-playbook playbook.yml
6. Задание со звездочкой на добавление динимеческого инвентаря, на данный момент есть возмжность добавить все в одну строчку как указано в ansible.cfg[inventory]
