В случае если ключи разные
ssh -J "name_прокладки@ip_прокладки -i ~/.ssh/id_rsa" -i ~/.ssh/id_rsa name_куда_прыгаем@ip_куда_прыгаем
Если ключ один и тот же на двух машинах можно сократить
ssh -i ~/.ssh/id_rsa -J name_прокладки@ip_прокладки name_куда_прыгаем@ip_куда_прыгаем

В файле конфигурации по адресу ~/.ssh/config прописать правила, если такого файла нет, то создать
Правила для файла конфигурации указываю ниже
Host bastion
    HostName bastion_ip
    User bastion
    Port <port number> - если порт отличается от стандартного 22
    IndentityFile ~/.ssh/id_rsa - опционально можно указать путь до файла с приватным ключем

Host someinternalhost
    HostName someinternalhost_ip
    User someinternalhost
    IdentityFile ~/.ssh/id_rsa
    ProxyJump bastion
