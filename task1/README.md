1. Запрет входа по ssh от имени root

   Заходим в файл конфигурации ssh - /etc/ssh/sshd_config
   Нужно разкомментировать строчку PermitRootLogin и установить флаг 'no'

   Далее нужно перезапустить службюу ssh через systemctl

   Сервера между собой пингуются и ходят по ssh, так как соединение на уровне L2 канальное, пингующий сервер орет в сеть "чей айпи", сервер с нужным айпи отвечает, ARP переводит айпи в мак адрес и записывает в кэш.
