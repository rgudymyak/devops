1. Запрет входа по ssh от имени root
   Заходим в файл конфигурации ssh - /etc/ssh/sshd_config
   Нужно разкомментировать строчку PermitRootLogin и установить флаг 'no'
   Далее нужно перезапустить службюу ssh через systemctl
   Сервера между собой пингуются и ходят по ssh из за того что они соеденены проводом, сигнал проходит через провод, а не через интернет.
   Машины соедененные между собой проводом, создают изолированную между собой сеть.
